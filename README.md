# حزمة HTML مستقلة — حسابات رحلتي

افتح `index.html` أو ارفع المجلد كاملًا إلى الاستضافة. الصفحات هي: `index.html`, `about.html`, `privacy.html`, `terms.html`, `contact.html`. ملف `styles.css` للهوية، و`script.js` لقائمة الهاتف.

النصوص القانونية مسودة تشغيلية وتحتاج مراجعة محامٍ وملء بيانات الكيان القانوني وبلد الاختصاص قبل النشر.
